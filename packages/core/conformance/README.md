# Conformance vectors

Generated by `npm run build:conformance` from the TypeScript core — do not edit by hand. Each `<function>.json` holds `{ schema, function, cases: [{ name, args, expected }] }`; `expected` is what the TS core returns for `args`. A consumer that re-implements a rule in another language (the Lua port in `neurovim.nvim`) vendors these files and must pass every case. A rule change here changes the vectors, so a lagging port fails visibly. `null` in `args` means "not set".

`getDiff` and `getDivergentLines` align lines along a longest common subsequence, and a port must align exactly the same way. Let `a` be the normalized lines of the current text and `b` those of the solution. Match the common prefix first (`p` lines), then the common suffix over what the prefix left (`q` lines; the suffix never overlaps the prefix). The middle is `a[p .. p+n)` against `b[p .. p+m)`, with `n = len(a) − p − q` and `m = len(b) − p − q`.

If `n·m > 250000` (500 × 500 lines) there is no table: every middle line of `a` is dropped, then every middle line of `b` is added, and the middle contributes nothing to the common count. This keeps a huge pasted text from freezing the game; a mission never comes near it. At exactly `n·m = 250000` the table is still built. Otherwise walk a suffix-LCS table `L[i][j]` over the middle from the top: when `a[i]` equals `b[j]`, keep both; otherwise drop `a[i]` if `L[i+1][j] >= L[i][j+1]`, else add `b[j]`. When one side is used up, the rest of the other is dropped (`a`) or added (`b`).

`lines_off = max(len(a), len(b)) − (p + q + LCS of the middle)`, with an LCS of 0 when the table is skipped. `first_divergent_line` is `p`, the length of the common prefix, and `-1` when the texts match. `getDivergentLines` marks every dropped line of `a` and, for each run of added lines that borders no dropped line, the line at its insertion point (the index of the next line of `a`), clamped to the last line (nothing for an empty text); marks are document indices, so add the frontmatter offset.

The vectors `tie: drop before add`, `changed first line before an equal line` and `prefix before suffix on repeated lines` fail a port that breaks ties the other way, skips the prefix/suffix step or matches the suffix first; the two `LCS cell limit` vectors fail a port without the limit or one that applies it at `n·m >= 250000`.

`recordCompletion`, `recordMissionRun` and `completeMission` take `today` as an argument, so no vector depends on a clock. A port that reads the day itself reads the player's **local** calendar day (`YYYY-MM-DD` from the local date fields, as the core's `localDay()` does), never the UTC day: between local midnight and the zone offset the two differ, and a streak counted by the UTC day breaks or doubles there. "Yesterday" is calendar arithmetic on that date string and must not go through local midnight, since a DST switch shifts it by an hour (the counter-check `a port computing yesterday from local midnight fails at DST` pins this).
