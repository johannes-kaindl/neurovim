# @neurovim/content

Versioned content source: missions (M-01..16, R-01..24), katas, loot, fragments, REF, story bible, world codex, characters.

Today the content lives as Obsidian Markdown in `32_NeuroVim/_content/` + `_dev/`. Phase 3 extracts it here with a Markdown→JSON build that `ContentSource` (web adapter) consumes. The Obsidian adapter continues to read from the vault (or likewise from this package — Open Question 3).
