## New here?

Start with the **[Tutorial](tutorial.md)** — it takes you from opening the game to
finishing your first mission, **CIPHER** narrating the whole way. You do not need to
know any Vim first; that is the point.

Then keep the **[Vim keymap reference](reference/vim-keymap.md)** open in a second tab
as a cheatsheet (the game has the same overlay built in).

## At a glance

NeuroVim is a Vim-learning game in disguise. An operator handler called **CIPHER**
assigns you "missions" — really Vim exercises — to restore CORP-corrupted documents
and beat the clock. There are three ways to play:

- **Story missions** — a ranked campaign that **unlocks progressively** as you level up.
- **KATAs** — short, story-free drills for one technique at a time.
- **THE RAVEN** — a free-play sandbox: fix N injected glitches against the clock.

Play in the browser (nothing to install) at
**<https://pages.jkaindl.de/neurovim-standalone/>**, or run it as a desktop app — see
[How-to: install the desktop app](how-to/index.md#install-the-desktop-app) or
[build it from source](how-to/index.md#build-the-desktop-app-from-source).
